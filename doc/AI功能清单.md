# AI 助手（爱宝）功能清单

> 入口：主页/部门页/管理页/个人中心的悬浮"爱宝"图标 → AI 助手对话页
> 模型：智谱 GLM（glm-4-flash），Function Calling 查询真实业务数据

---

## 〇、查询范围（2026-08-31 起支持三个模块）

| 模块 | 工具 | 说明 |
|---|---|---|
| 任务(计划) | getTasks | 时间/状态/类型/负责人/科室/关键词组合查询 |
| 会议安排 | getMeetings | 按天(date)或日期范围查询，自动兼容单日/跨天会议；支持名称关键词、主持人 |
| 重点工作(事件) | getWorks | 时间/状态/类型/负责人(姓名)/科室/关键词；权限与网页端一致(非学院领导只看公开) |

三个模块**共享对话上下文**：同一会话里先查"这周有什么会议"，再问"那任务呢"，时间范围自动继承、模块自动切换。回答中的名称可点击跳转对应详情页（任务/会议/重点工作三个详情页）。

## 一、任务查询（核心能力）

支持自然语言提问，以下条件可**任意组合**：

| 查询维度 | 示例问法 | 说明 |
|---|---|---|
| 关键词 | "查一下包含'评估'的任务" | 任务名称模糊匹配 |
| 任务状态 | "进行中的任务有哪些" | 自动把"进行中"解析为字典ID |
| 任务类型 | "科研申报类的任务" | 自动解析任务类型字典ID |
| 重要程度 | "紧急的任务" | 自动解析重要程度字典ID |
| 负责人 | "张三的任务"、"李四负责什么" | 自动把姓名解析为用户ID |
| 科室 | "信息化建设科的任务" | 自动把科室名解析为科室ID |
| 时间范围 | "本周的任务"、"最近三个月"、"下个月截止的" | 相对时间自动换算成具体日期 |
| 我的任务 | "我的任务"、"我最近完成了什么" | 第一人称强制只查自己申报的 |
| 组合查询 | "张三本周的紧急任务" | 多条件同时生效 |
| 分页追问 | "还有吗"、"下一页" | 单次最多返回20条，超出提示翻页 |

返回结果包含：任务名称、状态、重要程度、类型、负责人（已把ID转为姓名）、创建人、科室、起止时间。

## 二、能力边界（AI 会如实告知）

- ✅ **只支持任务（计划）查询**——只读，不改动任何数据
- ❌ 创建 / 修改 / 删除任务 → 引导去系统"新增任务"等页面操作
- ❌ 查询会议、重点工作 → 提示去对应功能页面（会议管理、重点工作）
- ❌ 查询任务附件、日志详情 → 当前未开放
- 不会泄露其他租户（学院）数据、不会绕过权限看到没权限的任务

## 三、智能纠错引导（输错了也能用）

| 用户可能的错误 | AI 的引导行为 |
|---|---|
| 姓名写错（"张三丰"不存在） | 列出系统里**实际存在的相近姓名**（最多5个）让用户确认，确认后才查询 |
| 有多个同名用户 | 列出同名用户及所在科室，请用户确认是哪一位 |
| 状态说法不规范（"搁置""挂起"） | 不硬套，列出系统实际状态（进行中/未开始/已完成/已撤销）让用户选 |
| 科室名不完整（"信息科"） | 列出相近的完整科室名让用户确认 |
| 条件都对但结果为 0 | 指出最可能导致无结果的条件（时间过窄/姓名科室有误），给出放宽建议并**主动用放宽条件重查** |
| 问题超出能力范围 | 说明当前仅支持任务查询，引导去系统对应页面 |

## 四、语音输入

- 按住"按住 说话"按钮开始录音，松开自动识别并发送
- 录音要求与限制：最长 30 秒（超时自动提交）；说话时间太短（<0.5秒）提示重说
- 识别引擎：智谱 GLM-ASR（glm-asr-2512，付费模型），浏览器需允许麦克风权限（H5 部署需 HTTPS）
- **澄清选项**：需求模糊时（如只说"查任务"），AI 会反问并在气泡下方给出 2~4 个可点击选项，点选即作为新消息发送——语音用户无需再打字或重说一遍
- **任务详情跳转**：AI 回答中出现的任务名称渲染为可点击链接（蓝色下划线），点击跳转到现有任务详情页查看完整信息；点选澄清选项后 AI 直接用默认条件查询，不连续追问

## 五、思考过程展示

- 提问后 AI 气泡内出现"思考过程"卡片，步骤**逐条实时浮现**：
  - 正在理解你的问题…
  - 查阅任务字典，确认状态/类型/重要程度的可选值…
  - 正在把「张三」解析为系统用户…
  - 按条件检索任务列表…
  - 查询完成，正在汇总结果…
- 步骤是后端 Function Calling 的**真实执行轨迹**，不是假动画
- 思考结束自动折叠（标题变"已完成思考"），点击可展开回看；答案以打字机效果逐字输出

## 六、历史会话管理

| 功能 | 说明 |
|---|---|
| 自动保存 | 每轮问答自动存到服务端（换设备登录也能看到） |
| 默认恢复 | 进入页面自动恢复最近一次对话 |
| 历史列表 | "历史对话"按钮打开抽屉，按最近活跃倒序（最多显示50条） |
| 切换会话 | 点击任一历史会话继续聊（带完整上下文） |
| 新对话 | "+ 新对话"清空当前上下文重新开始 |
| 删除会话 | 二次确认后删除；会话软删、消息物理删除，不留痕。入口有两个：聊天页工具栏"删除记录"（删当前会话，无会话时不显示）、历史抽屉每条的"删除" |
| 删除单轮问答 | 每条**用户消息**气泡下方有"删除"入口，二次确认后删除该轮提问+AI回答（物理删除，其余轮次保留）；刚发完的消息也能删；删空整个会话时连带删除会话 |

## 七、多端一致性

- 网页端对话页与独立测试页 `ai-test.html` 共用同一后端与会话数据
- 同一账号在任一入口发起的对话，历史记录互通
