## 发现的问题

1. **存根接口**：TenantController 全部3个接口、UserController 3个查询接口（getUserByStatus/searchUserByUid/searchUserByUname）仅返回空 Result，业务逻辑未实现。
2. **未实现逻辑**：RoleController.assignPermission 业务代码已注释，实际未生效。
3. **返回格式不统一**：SysTemplateController 的4个接口直接返回 HashMap 而非统一 Result 对象。
4. **疑似Bug**：PlanController.getPlanLogByPid 和 WorksController.getWorksLogByPid 调用 service 方法后返回 `Result.success()` 未传入 data。
5. **RESTful规范偏差**：ScreenConfigController.deleteConfig 使用 GET 方法执行删除操作，建议改为 DELETE。
6. **空控制器**：InformController 和 SaasController 类体为空，对应功能模块尚未开发。

## 文档结构

接口文档按控制器模块分章节，每个接口以表格形式记录：
- 接口地址（含完整路径）
- HTTP 方法
- 接口作用
- 接口参数（含参数类型和位置）
- 接口返回值
- 备注（含权限说明、注意事项）
