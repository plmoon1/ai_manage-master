## 通用说明

### 统一返回格式 `Result`

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | String | 状态码，"200" 表示成功，其他表示异常 |
| `msg`  | String | 提示信息 |
| `data` | Object | 返回数据（可为 null、单个对象、列表或分页对象 PageInfo） |

### 分页返回格式 `PageInfo<T>`

| 字段 | 类型 | 说明 |
|------|------|------|
| `total` | Long | 总记录数 |
| `list`  | List\<T\> | 当前页数据列表 |
| `pageNum` | Integer | 当前页码 |
| `pageSize` | Integer | 每页条数 |
| `pages` | Integer | 总页数 |
